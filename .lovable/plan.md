

# Clean Up Proposal-Generated Slots on Reset + Show Existing Slots as "Blocked"

## The Problem

When `resetProposals()` runs, it only:
1. Deletes `proposed_assignments`
2. Resets `intake_requests` status back to `new`

It does **not** delete the `availability_slots` that were generated by the proposal engine (those with `cyclus_id = cycleId`). These orphan slots remain in the trainers' agendas, which is what you're seeing.

Additionally, when viewing the proposal schedule grid, trainers may have pre-existing slots (non-cycle, `cyclus_id IS NULL`) that overlap with the cycle's time range. These should appear as "blocked" cells so the manager knows that time is unavailable.

## Plan

### 1. Delete cycle slots on reset (`src/lib/cycles.ts` — `resetProposals`)

Add a **Step 0** before the existing steps: delete all `availability_slots` where `cyclus_id = cycleId`. This mirrors what the generate-proposals edge function already does at line 500-502 before re-generating.

```
// New Step 0: Delete generated availability slots for this cycle
DELETE FROM availability_slots WHERE cyclus_id = cycleId
```

### 2. Fetch existing (non-cycle) slots and pass them as "blocked" (`src/lib/cycles.ts` — `getAvailableSlotsForCycle`)

After fetching cycle slots, also fetch non-cycle slots (`cyclus_id IS NULL`) for the same trainers within the cycle's date range. Return these separately with a `is_blocked: true` flag.

Add `is_blocked?: boolean` to `SlotWithOccupancy`. Cycle slots get `is_blocked: false`, existing trainer slots get `is_blocked: true` with empty `current_assignments`.

### 3. Render blocked slots in the grid (`src/components/cycles/ProposalScheduleGrid.tsx`)

For slots with `is_blocked: true`:
- Render with a distinct muted/striped style (e.g., gray background with diagonal stripes or a "Blocked" label)
- Make them non-interactive (no drag-drop, no player assignment)
- Show a tooltip or label like "Existing lesson" so the manager understands why

### Files to Change

| File | Change |
|------|--------|
| `src/lib/cycles.ts` | Add slot deletion to `resetProposals()`. Add blocked slot fetching to `getAvailableSlotsForCycle()`. Add `is_blocked` to `SlotWithOccupancy`. |
| `src/components/cycles/ProposalScheduleGrid.tsx` | Render blocked slots with distinct styling, skip drag-drop for them. |
